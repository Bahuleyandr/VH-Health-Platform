# VH Health Backend API

VH Health Backend API for managing patient profiles, appointments, health records, investigations, pharmacy orders, and feedback.

## 🛠️ Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Swagger UI Documentation
- Rate Limiting & API Key Protection

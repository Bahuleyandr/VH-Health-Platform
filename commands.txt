npm run start:render — Uses .env.render

npm start — Defaults to production setup (src/bin/www.js)

✅ Developer Utilities
npm run dev — Starts with nodemon for auto-reloading

npm run lint — Runs ESLint for code quality checks

npm run test — Placeholder for tests

✅ Admin Tools & Maintenance
npm run purge:logs — Purges old logs

npm run backup-db — Dumps database to backups/

npm run restore-db — Restores database from latest or specified dump

npm run cleanup-logs — Cleans old application logs

✅ R2 Storage Utilities
npm run r2-list — Lists files in R2 storage bucket

npm run r2-cleanup — Removes files older than retention policy

✅ Schema & API Validation
npm run validate-schema — Validates database schema

npm run validate-swagger — Validates Swagger/OpenAPI definitions

npm run generate-swagger — Regenerates Swagger documentation

✅ Permission & Ownership Tools
npm run fix-permissions — Fixes file/directory permissions for cross-platform compatibility
